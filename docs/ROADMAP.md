## 关键决策点

### 决策 1: 移动端技术选型（Phase 2 开始前）

**选项：**
- A) React Native - 复用 React 代码，开发效率高
- B) Flutter - 性能更好，UI 一致性更强
- C) PWA - 开发成本最低，但功能受限

**建议：** 先做 PWA 验证需求，再决定是否投入原生开发

### 决策 2: 云端服务架构（Phase 3 开始前）

**选项：**
- A) 自建后端（Node.js + PostgreSQL）- 完全掌控
- B) BaaS（Supabase / Firebase）- 开发快，但依赖平台
- C) 去中心化（IPFS + 加密）- 最安全，但复杂

**建议：** 先用 Supabase 快速验证，用户量起来后再考虑迁移

### 决策 3: AI 模型策略（持续评估）

**选项：**
- A) 纯云端（Claude/GPT-4）- 能力最强，但有成本
- B) 纯本地（Ollama）- 隐私最好，但能力有限
- C) 混合（本地预处理 + 云端深度分析）- 平衡

**建议：** 采用混合策略，敏感数据本地处理，复杂分析用云端

## 风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|----------|
| AI 模型成本过高 | 高 | 本地模型优先，云端模型按需使用 |
| 用户坚持不下来 | 高 | 降低记录门槛，增加游戏化元素 |
| 数据隐私泄露 | 极高 | 本地优先，端到端加密，开源审计 |
| 技术栈不成熟 | 中 | 提前验证关键技术，准备降级方案 |
| 开发周期过长 | 中 | 严格按 MVP 思路，先上线再迭代 |
