# SelAi 产品规划

## 产品形态分析

### 现有竞品与市场观察

通过分析市场上的相关产品，我们发现了几个主要方向：

| 产品类型 | 代表产品 | 优势 | 不足 |
|---------|---------|------|------|
| AI 日记/日志 | Diary AI, Day One | 记录体验好 | 缺乏决策辅助能力 |
| 生活数据追踪 | Aeonlog, 录音豆 | 数据采集全面 | 数据锁定在平台内 |
| 数字分身/传记 | 数字人生 App | 有 AI 对话能力 | 偏向回忆记录，不面向未来决策 |
| 决策日志 | Decision Trail | 聚焦决策场景 | 缺乏生活数据关联 |
| AI 助手 | Today AI, Claude | AI 能力强 | 不专注个人生活数据积累 |

### SelAi 的差异化定位

**SelAi = 生活数据底座 + AI 分析引擎 + 决策辅助系统**

核心差异点：
1. **数据主权** - 本地存储，不锁定平台
2. **全维度记录** - 不只是日记，涵盖健康/财务/社交/学习/情绪
3. **决策导向** - 不只是回顾，更面向未来的选择
4. **模型无关** - 可接入不同 AI 模型，交叉验证
5. **渐进式积累** - 从第一天就有价值，越用越精准

## 产品形态建议

### 推荐方案：本地优先的桌面/移动应用

**为什么不是纯 Web 应用？**
- 隐私考虑：生活日志是高度个人化的数据，本地存储更安全
- 离线可用：不依赖网络，随时随地记录
- 数据主权：用户完全掌控自己的数据

**为什么不是纯命令行工具？**
- 目标用户是普通年轻人，不是开发者
- 需要低摩擦的记录体验
- 可视化报告和交互界面很重要

**推荐形态：**
- **Phase 1 (MVP):** 本地 Web 应用（Electron / Tauri）+ 本地文件系统存储
- **Phase 2:** 增加移动端（React Native / Flutter），数据同步
- **Phase 3:** 可选云端备份、多设备同步

## 核心功能模块

### 1. 生活日志记录模块 (Life Logger)

**目标：** 以最低摩擦记录日常生活的各个维度

**数据类型：**
- 健康数据：饮食、睡眠、运动、体重、情绪
- 工作/学习：任务完成情况、专注时间、技能进展
- 财务数据：收入、支出、投资
- 社交数据：与谁见面、社交活动、人际关系变化
- 想法/灵感：随想、反思、创意
- 决策记录：做了什么决定、为什么、预期结果

**记录方式：**
- 快速文字输入（支持自然语言）
- 语音转文字
- 图片 + AI 自动标注
- 传感器数据自动导入（Apple Health, 微信步数等）
- 模板化快速记录（早间/晚间模板）

**关键设计：**
- 一条记录 < 10 秒完成
- 支持碎片化记录，AI 负责结构化
- 自动打标签、分类、关联

### 2. AI 分析引擎 (AI Analyzer)

**目标：** 将原始生活数据转化为有价值的洞察

**核心能力：**

#### 2.1 定期报告
- **日报** - 今日概要、关键数据、明日建议
- **周报** - 本周趋势分析、目标完成度、下周规划
- **月报** - 月度深度分析、生活各维度评分、长期趋势
- **年度报告** - 人生年度回顾与展望

#### 2.2 模式识别
- 情绪周期与触发因素分析
- 消费习惯与财务趋势
- 作息规律与健康关联
- 社交模式与人际关系网络
- 生产力波动与高效时段

#### 2.3 异常检测
- 「你最近一周的睡眠时间比上月平均减少了 1.5 小时」
- 「你的运动频率已经连续 2 周低于目标」
- 「你的情绪在过去 3 天持续走低，可能与 XX 事件相关」

#### 2.4 关联发现
- 「每次你加班到 10 点以后，第二天的外卖消费会增加 60%」
- 「你在周末的社交活动后，下周的专注时间平均提高 20%」
- 「你的运动量和情绪评分有 0.85 的正相关性」

### 3. 决策辅助模块 (Decision Advisor)

**目标：** 在人生重大选择时，提供数据驱动的多维度分析

**核心功能：**

#### 3.1 决策记录
```markdown
## 决策：是否换工作到 XX 公司

### 背景
- 当前工作：...
- 新机会：...

### 选项
1. 接受新 offer
2. 留在当前公司
3. 继续观望

### 预期结果
- 选项 1：薪资 +30%，但通勤时间 +45min/天
- 选项 2：稳定，但成长空间有限
- 选项 3：保持灵活性，但可能错过机会

### AI 分析
基于你的历史数据：
- 你过去 3 份工作平均 18 个月换一次，当前工作已 20 个月
- 你的成长需求评分持续走高，当前岗位满足度下降
- 你的财务数据显示你有 6 个月的 emergency fund，可以承受风险
- 你重视 work-life balance，新工作的加班文化可能与此冲突

### 建议
综合来看...
```

#### 3.2 事前预演 (Pre-mortem)
- 在做决策前，让 AI 模拟不同选择的可能结果
- 基于历史数据识别你容易犯的认知偏差
- 提供「魔鬼代言人」视角，挑战你的假设

#### 3.3 事后复盘 (Post-mortem)
- 决策后定期追踪实际结果
- 对比预期与实际，分析偏差原因
- 积累经验，优化未来决策质量

#### 3.4 多模型交叉验证
- 同一个决策问题，可以同时咨询多个 AI 模型
- 对比不同模型的建议，找到共识和分歧
- 用户可以选择最信任的模型，或取中间值

### 4. 个人数据面板 (Dashboard)

**目标：** 直观展示个人生活的全景视图

**核心视图：**
- **时间轴视图** - 按时间浏览所有记录
- **维度视图** - 按健康/工作/财务/社交等分类查看
- **趋势图** - 关键指标的变化趋势
- **关系图谱** - 不同维度之间的关联
- **AI 洞察卡片** - 每日/每周的个性化发现

### 5. 数据管理模块 (Data Manager)

**目标：** 确保数据主权和可迁移性

**核心功能：**
- **本地存储** - 所有数据以 Markdown/JSON 格式存储在本地
- **导出功能** - 一键导出全部数据，支持多种格式
- **导入功能** - 从其他平台（日记 app、健康 app）导入历史数据
- **备份与恢复** - 本地备份、可选云端加密备份
- **数据清理** - 批量删除、匿名化处理

## 用户旅程示例

### 场景 1：日常记录

```
早上 8:00 - 打开 SelAi，快速记录：
  "昨晚睡了 7 小时，感觉不错。今天计划完成项目方案。"
  → AI 自动识别：健康(睡眠) + 工作(任务)

中午 12:30 - 拍一张午餐照片
  → AI 自动识别：饮食记录，估算热量

晚上 22:00 - 语音记录 30 秒：
  "今天工作效率不错，方案完成了 80%。下午有点焦虑，可能是因为 deadline 临近。"
  → AI 自动转文字，识别：工作效率 + 情绪(焦虑)
```

### 场景 2：周报复盘

```
周日晚上 - SelAi 自动生成周报：

## 本周概要
- 工作满意度：8/10（较上周 +1）
- 平均睡眠：7.2 小时（达标）
- 运动次数：3 次（目标 4 次，差 1 次）
- 情绪趋势：整体平稳，周三有一次低谷

## AI 洞察
- 你本周的焦虑集中在工作日下午，与 deadline 相关
- 运动日的第二天，你的专注时间平均提高 25%
- 你的社交时间本周较少（仅 2 小时），上月平均 5 小时

## 下周建议
- 尝试在周三下午安排一次运动，可能有助于缓解焦虑
- 考虑本周安排一次社交活动
```

### 场景 3：重大决策

```
用户输入：
"我在考虑要不要从北京搬到上海，帮我分析一下"

AI 分析过程：
1. 检索过去 2 年的生活数据
2. 分析关键维度：
   - 工作：上海有 XX 机会，但当前北京的人脉网络更强
   - 财务：上海生活成本 +15%，但薪资预期 +20%
   - 社交：北京有 15 个常联系朋友，上海仅 3 个
   - 生活偏好：你更喜欢安静，上海可能更适合
   - 历史模式：你过去 3 次搬家后都有 3-6 个月的适应期

3. 生成多维度分析报告
4. 提供 3 个方案（乐观/中性/保守）
5. 建议「先在上海试住 1 个月」作为低风险验证方式
```

## 技术实现考量

### 数据存储格式

推荐使用 Markdown + YAML Front Matter：

```markdown
---
date: 2026-11-03T08:00:00+08:00
type: daily_log
tags: [health, work, emotion]
mood: 7
sleep_hours: 7
---

## 今日记录

昨晚睡了 7 小时，感觉不错。今天计划完成项目方案。
```

优势：
- 人类可读可编辑
- 版本控制友好（Git）
- AI 模型容易理解
- 不依赖任何特定软件

### AI 接入策略

- **本地优先：** 支持本地模型（Ollama, LM Studio）处理敏感数据
- **云端可选：** 支持 Claude, GPT-4, 智谱等云端模型获取更强能力
- **多模型：** 重要决策可并行咨询多个模型
- **渐进式：** 先用简单规则，逐步引入 AI 能力

## MVP 范围定义

### Phase 1: 最小可行产品（4-6 周）

**核心功能：**
1. 文本日志记录（Markdown 格式，本地存储）
2. 基础 AI 分析（日报/周报生成）
3. 简单的数据面板（时间轴 + 标签筛选）
4. 数据导出（JSON/Markdown）

**技术栈：**
- 前端：React + TypeScript
- 桌面：Tauri（轻量级，Rust 后端）
- 存储：本地文件系统 + SQLite 索引
- AI：Claude API / 本地 Ollama

**不包含：**
- 移动端
- 语音/图片输入
- 传感器数据自动采集
- 多模型交叉验证
- 云端同步

### Phase 2: 增强版（+4-6 周）

- 移动端适配（React Native 或 PWA）
- 语音输入 + AI 转文字
- 图片记录 + AI 标注
- 决策辅助模块
- 多模型支持

### Phase 3: 完整版

- 传感器数据集成（Apple Health, 微信步数等）
- 云端加密备份
- 多设备同步
- 高级数据可视化
- 社区功能（可选）

## 成功指标

### 产品指标
- 日活用户记录频率 > 1 次/天
- 用户平均记录持续时间 > 30 天
- 周报/月报查看率 > 60%

### 用户价值指标
- 用户主观评价：「SelAi 帮助我更了解自己」
- 决策质量提升：用户反馈 AI 建议的有用性
- 数据积累量：平均每用户 > 100 条记录
